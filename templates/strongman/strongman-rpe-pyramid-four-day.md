# Four-Day Strongman RPE Pyramid Cycle

> Educational programming only; this is not medical advice. Get clearance from a doctor or qualified clinician before starting a full plan.

## Gist

- A 12-week follow-on to the four-day compact strongman cycle for an athlete who found the fixed-volume weeks repetitive and wants a faster, RPE-led build.
- Keep log clean and press, deadlift, and a conventional barbell back squat as the main pyramids. Day 3 prioritizes upper-back strength with a seated low-cable row before close-grip Slingshot bench. The heaviest prescribed set is always at least three reps; there are no singles.
- The rep wave borrows 5/3/1's change in emphasis, but load is chosen by RPE rather than a training-max percentage. This is not a copy of a 5/3/1 program.

## Starting Point

- Finish the current testing week, then take several easy days or a light week if fatigue is high. Start Week 1 only when the next session is likely to be productive.
- Use the recent clean triple or closest comparable lift to choose the first ramp loads. Do not turn Week 1 into another test. The top-set RPE is the ceiling, not a target to exceed.
- Assumes general strongman training, four sessions of about 45-60 minutes, and a home gym with a log, barbell, rack, bench, Slingshot, and a single-stack cable pulley with a low position. Day 3 uses the cable stack, bench, and rack; it has no carry equipment or chest-supported row setup. If a future contest has carry or loading events, add specific practice in a separate contest-prep block.

## How Each Main Lift Works

1. Warm up, then pyramid through 2-3 ascending work sets: `1 x 5 @ RPE 6`, `1 x 3-5 @ RPE 7`, and, when the top triple needs it, `1 x 3 @ RPE 8`.
2. Take **one top set** at the week's listed reps and RPE. Stop the climb if positions or bar speed break down. No singles and no automatic AMRAP.
3. Reduce the load enough to hit the listed backoff RPE, usually about 5-10% as a starting guess, then complete the backoffs. Adjust by feel instead of forcing the percentage.
4. Log top-set load, reps, actual RPE, backoff load, and any missed reps. If the top set overshoots by more than about 0.5 RPE or recovery suffers, hold or reduce load next exposure; do not chase the planned increase.

| Week | Emphasis | Top set for log, deadlift, back squat | Backoffs for those lifts |
| --- | --- | --- | --- |
| 1 | Volume with pace | `1 x 6 @ RPE 8` | `2 x 6 @ RPE 7-8` |
| 2 | Moderate load | `1 x 5 @ RPE 8.5` | `2 x 5 @ RPE 7-8` |
| 3 | Heavy triple | `1 x 3 @ RPE 9` | `2 x 3 @ RPE 7-8` |
| 4 | Pivot | `2 x 5 @ RPE 6-7`; no top set | — |
| 5 | Volume with a new support variation | `1 x 6 @ RPE 8` | `2 x 6 @ RPE 7-8` |
| 6 | Moderate load | `1 x 5 @ RPE 8.5` | `2 x 5 @ RPE 7-8` |
| 7 | Heavy triple | `1 x 3 @ RPE 9` | `2 x 3 @ RPE 7-8` |
| 8 | Pivot | `2 x 4 @ RPE 6-7`; no top set | — |
| 9 | Specific volume | `1 x 5 @ RPE 8` | `2 x 5 @ RPE 7-8` |
| 10 | Specific load | `1 x 4 @ RPE 8.5` | `2 x 4 @ RPE 7-8` |
| 11 | Final heavy triple | `1 x 3 @ RPE 9` | `1-2 x 3 @ RPE 7-8` |
| 12 | Deload or controlled triple test | Default `2 x 3 @ RPE 6-7`. If recovered, test **one** priority lift with `1 x 3 @ RPE 9`, then stop. | None after a test |

The RPE sequence reaches productive work in Week 1 and rises within each three-week wave. The Week 5-7 and 9-11 waves should usually use more load than the earlier wave at comparable RPE, provided the reps and recovery support it. The lower-volume pivot weeks protect the next wave. Four top sets at RPE 9 may be too costly; cap the deadlift at RPE 8-8.5 first if recovery slips.

## Four-Day Layout

| Day | Focused slot, 18-25 min | Support slot, 12-18 min | Accessory slot, 8-12 min |
| --- | --- | --- | --- |
| 1 | Log clean and press pyramid; **clean every rep** | Raw flat bench `2-3 x 5-8 @ RPE 7-8` | Cable face pull or rear fly `2-3 x 12-20 @ RPE 7-8` + cable curl if time |
| 2 | Deadlift pyramid | Glute-bridge hamstring walkout `2-3 x 6-10 @ RPE 7-8` + dead bug `2-3 x 8-12/side @ RPE 7` | Cable pressdown or rear fly `2 x 12-20 @ RPE 7` if recovered |
| 3 | Seated low-cable row `3 x 6-10 @ RPE 7-8`, torso steady and feet braced against a fixed support | Close-grip Slingshot bench `2-3 x 3-5 @ RPE 7-8` | Barbell shrug from rack height `2-3 x 8-12 @ RPE 7-8` + cable rear fly or face pull `2 x 12-20 @ RPE 7` |
| 4 | Barbell back squat pyramid in your usual bar position and stance | Log press, **clean once and press away** `2-3 x 5-8 @ RPE 7` | Cable pulldown or face pull `2-3 x 8-15 @ RPE 7-8` |

## Variety Without Losing the Thread

- Weeks 1-3: log clean each rep, raw flat bench after log, usual deadlift, low-cable row plus close-grip Slingshot bench, and barbell back squat. Keep Day 4's clean-once log work lighter than Day 1.
- Weeks 5-7: keep those patterns while varying the cable-row grip, cable rear-delt angle, and hamstring-walkout difficulty. Keep the Sling Shot on Day 3 only; judge its RPE on the assisted lift and do not compare its load with raw bench. Do not add an RDL when the lower back needs deadlift recovery.
- Weeks 9-11: return the main lifts to the forms you want to measure. Keep accessories familiar and trim one round if they slow recovery. Day 3 Slingshot remains a support lift, not a max test.
- Change at most one support exercise per slot at a wave boundary. Variety should make the volume phase engaging without making every week incomparable.

## Adjustment Rules

- Main lift top set comes before backoffs. If time is short, remove an accessory round, then a backoff set; preserve the main top set.
- Day 3's low-cable row needs a fixed foot brace aligned with the cable: use the rack's stable lower crossmember if it fits the layout, or a properly mounted row footplate. Do not brace against the pulley housing, a loose barbell, or movable equipment. Sit on the floor or a low, stable seat, keep the torso nearly upright, and pull without rocking. If a secure foot brace is unavailable, use a one-arm cable row with the free hand supported on the rack and a staggered stance.
- Set the barbell for shrugs around thigh height in the rack and stay upright. Use moderate loading; omit shrugs if they create lower-back fatigue before Day 4 squats. Cable face pulls remain the low-fatigue fallback.
- If hamstring walkouts are too difficult, use a short-range glute bridge with alternating heel steps. A cable leg curl is an alternate only if the stack has a low pulley and an ankle attachment.
- If the current testing week exposes a clear weak link, choose the support variation that addresses it; do not change the four main priorities without a goal reason.
- If a contest later requires carries or loading, this general block does not supply that practice; use an event-specific prep block for the announced events.

## Assumptions Review

- This is a general strongman follow-on without carries, not a dated contest peak. A real event list and date could require separate event practice.
- Testing loads, injury limits, and actual recovery data were not supplied. Use RPE to set the first loads and adjust the wave after reviewing the completed testing results. The program uses only the home-gym equipment reported by the athlete.
- The revised plan keeps the four-day, 45-60 minute structure and caps the heaviest sets at triples, as requested.
